Offline PWA demo

Serve this folder over http://localhost (service workers need a secure context). Use the download control on the player, throttle to Slow 3G, then go offline / airplane mode and reload.

  1. Open DevTools → Network → Slow 3G.
  2. Click Download for offline on the player.
  3. Enable Offline (or airplane mode on a phone) and reload.
  4. Audio, captions and transcript should still work from Cache API + IndexedDB.
  5. Click again to Remove offline copy.
  6. With Amharic captions loaded, use Export Amharic Braille (.brf) in the control bar beside captions (loads sibling abol-player.braille.js — experimental).
