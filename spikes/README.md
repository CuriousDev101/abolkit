# spikes

Timeboxed experiments (1-2 hours each) that settle open choices with evidence. One folder per spike, named `NN-topic` where NN is the issue number (for example `05-player-engine`). Each folder has a `RESULT.md` copied from `_template/RESULT.md`, plus any throwaway code. Spike code is not production code: copy what you need into `packages/` or `services/` in a proper PR.

Spikes: #5 player engine · #6 host baseline · #7 STT · #8 TTS · #9 ffmpeg · #10 zod-openapi · #11 storage/queue/db · #12 offline · #13 Ethiopic · #14 Open Badges and JobPosting.
